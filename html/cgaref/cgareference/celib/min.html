min function

float min(a, b)
string min(a, b)
float[] min(a, b)
string[] min(a, b)

a floatstringfloat[]string[]

b floatstringfloat[]string[] Must be the same type as a.

Returns the minimum of a and b. For arrays, the operation is applied element-wise and an array with the pairwise minima is returned.

Related

maxfunction

Examples

min(10, -10)
# result = -10

min("abc", "def")
# result = "abc"

Asset Search

Asset and texture search: Now the search for an inserted asset or texture is always relative to the rule file. This is also the case for imported rule files.

The search order is as follows: 1) if userPath is an absolute workspace path, that is, starts with "/", return that file, 2) try to resolve relative to "assets" in the project where the rule file resides, 3) try to resolve relative to the project. No search heuristics are applied anymore, so for instance the asset "assets/windows/window1.obj" must be inserted as i("windows/window1.obj").

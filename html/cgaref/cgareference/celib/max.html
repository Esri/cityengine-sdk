max function

float max(a, b)
string max(a, b)
float[] max(a, b)
string[] max(a, b)

a floatstringfloat[]string[]

b floatstringfloat[]string[] Must be the same type as a.

Returns the maximum of a and b. For arrays, the operation is applied element-wise and an array with the pairwise maxima is returned.

Related

minfunction

Examples

max(10, -10)
# result = 10

max("abc", "def")
# result = "def"

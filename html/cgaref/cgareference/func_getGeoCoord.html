getGeoCoord function

float getGeoCoord(geoCoordinate)

geoCoordinate selector

X, Y Selects the 2D coordinate of the current scene's coordinate system, for example UTM easting and northing coordinates. These values are always returned in the scene coordinate system's units.
lon, lat Selects spherical latitude and longitude coordinates in WGS84.

Returns the selected coordinate of the origin of the scope of the current shape.

The getGeoCoord function converts the current scope position to geographical 2D coordinates.

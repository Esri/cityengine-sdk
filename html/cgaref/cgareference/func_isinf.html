isinf ("is infinite") function

bool isinf(value)
bool[] isinf(values)

value float

values float[]

Returns true if value is infinite, and false otherwise. For arrays, the function is applied element-wise and returns a new array with the boolean results.

Related

isnanfunction

Examples

isinf(1)
# result = false

isinf(1/0)
# result = true

isinf(ln(0))
# result = true

isinf([1, 1/0])
# result = [false, true]

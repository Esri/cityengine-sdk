colorHexToG function

float colorHexToG(hexValue)

hexValue string Hexadecimal color string in the format "#rrggbb" or "#rrggbboo"

Returns the G value in [0,1] after converting a hexadecimal color to RGB.

This function converts a hexadecimal color string to RGB and returns the G value.

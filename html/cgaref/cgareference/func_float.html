float function

float float(value)

value floatboolstring Value to convert.

Returns the value converted to float.

This function converts value to the corresponding float value.

Related

Examples

float("0.5")
# result = 0.5

float(true)
# result = 1

float("001.5")
# result = 1.5

float(1/0)
# result = inf

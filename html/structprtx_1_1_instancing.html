enum prtx::Instancing::Action

Modes for deciding how cached/identical geometry objects are emitted as instances.

Instancing means that identical cached geometry is shared as prototype geometry and referenced by multiple finalized instances with their own transformations and materials, instead of duplicating the geometry for each occurrence.

Enumerator
NONE 

No instancing.

ALL 

All cached/identical meshes are treated as instances.

NO_SMALL_CGA_PRIMITIVES 

All cached/identical meshes except small CGA primitives, such as primtiveCube/Disk/Quad, are treated as instances. This improves performance when e.g., renderer is not optimized for instancing while still reducing file size for larger assets.
